# laundry time.

크림색 작은 세탁기와 토마토 친구들이 함께하는 웹 뽀모도로 타이머.

**[라이브 데모 열기](https://jeiel85.github.io/laundry-time/)**

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm ci
npm run dev
```

터미널의 로컬 주소로 접속합니다. 배포용 정적 파일은 `npm run build`로 `dist/`에 생성합니다. `npm run preview`로 배포 빌드를 확인하고 `npm test`로 타이머 로직을 검증합니다.

## 라이브 데모 배포

`main`에 푸시하면 GitHub Actions가 의존성 설치 → 타이머 테스트 → 빌드 → GitHub Pages 배포를 수행합니다. `.github/workflows/pages.yml`의 `workflow_dispatch`로 수동 배포도 가능합니다. GitHub Pages용 빌드만 `--base /laundry-time/`을 지정하므로 로컬 실행과 다른 호스팅의 기본 빌드는 그대로 사용할 수 있습니다.

## 사용

- 집중 세탁 25분, 짧은 휴식 5분, 긴 휴식 15분. 설정에서 각각 변경할 수 있습니다.
- 집중 세탁을 4회 완료하면 긴 휴식으로 넘어갑니다. 다음 코스는 사용자가 시작합니다.
- 시작/일시정지: 버튼 또는 Space. 처음으로: 타이머 옆 화살표.
- ‘멍 때리기’는 시간 제한 없이 세탁기가 돌아가는 모드입니다.
- 세탁기를 누르면 잠깐 더 덜컹거립니다. 포인터를 따라 살짝 시점이 달라집니다.
- 드럼은 실제 세탁 단계의 속도를 참고해 40 RPM(1.5초에 한 바퀴)으로 회전하며 부드럽게 가속·감속합니다. 기준: [NXP AN3234 §4](https://www.nxp.com/docs/en/application-note/AN3234.pdf)의 일반 세탁 속도 30–45 RPM. 몸체의 덜컹거림은 작게 유지합니다.
- 오른쪽 위 스피커로 합성 세탁 소리와 완료 알림을 켭니다. 기본은 무음이며, 새로고침 뒤에는 사용자 동작 후 오디오가 활성화됩니다.
- 동작 줄이기 설정과 기기의 `prefers-reduced-motion`을 존중합니다.

## 구현 결정

Three.js + Vite + 기본 JavaScript를 사용했습니다. 실제 입체 회전과 조명, 그림자 표현이 필요해 Three.js를 선택했고, 단일 화면의 작은 앱이므로 UI 프레임워크와 물리 엔진은 추가하지 않았습니다. 둥근 상자·구·곡선·고리로 모든 물체를 직접 모델링합니다. 원본 시안 이미지는 참조용이며 앱에 포함하지 않습니다.

외부 이미지·3D 모델·텍스처·웹폰트·음원·CDN을 사용하지 않습니다. 세탁기 화면은 Canvas, 아이콘은 직접 작성한 SVG, 소리는 Web Audio로 생성합니다. Three.js와 Vite는 npm 의존성이며 배포 시 필요한 코드가 정적 빌드에 포함됩니다. 런타임 외부 요청이나 분석 도구는 없습니다.

타이머는 종료 시각을 기준으로 계산해 백그라운드 탭의 타이머 지연을 보정합니다. 설정·진행 중인 타이머·오늘의 완료 기록은 브라우저 `localStorage`에 저장되며 날짜는 사용자 기기의 현지 날짜를 따릅니다. 브라우저를 닫으면 소리는 나지 않으며 다시 열면 종료 여부를 확인합니다. 저장소를 사용할 수 없으면 안내 후 메모리에서 동작합니다. 서버·계정·사용자 데이터 전송은 없습니다.

3D 화면에는 WebGL 2가 필요합니다. 사용할 수 없는 환경에서는 안내를 표시하며 타이머는 계속 동작합니다.

## 구성

- `src/scene.js`: 직접 생성한 3D 세탁기, 토마토, 수건, 바구니와 애니메이션
- `src/timer.js`: 종료 시각 기반 타이머, 코스 전환, 기록 복원
- `src/audio.js`: 브라우저 내 소리 합성
- `src/main.js`: 화면과 조작, 설정 및 기록 저장
- `src/style.css`: 세탁기와 타이머 중심의 반응형 화면
- `tests/timer.test.js`: 시간 지연·완료 중복 방지·휴식 주기·저장값 검증
